# Roadmap

This portfolio doubles as an **open-source template**: anyone can use the repository as a
starting point for their own interactive 3D site. The roadmap focuses on making that easy.

## Vision

A fast, accessible and beautiful portfolio that people can personalise in minutes by editing
one data file, without touching component code.

## Milestones

### Now

- [ ] Respect `prefers-reduced-motion` for the cursor, marquee and reveal animations
- [ ] Add Lighthouse CI with performance and accessibility budgets
- [ ] Skip link, visible focus styles and full keyboard navigation

### Next

- [ ] Move projects, certifications and contact links into `src/data/*.json`
- [ ] Static fallback for devices without WebGL or on low power
- [ ] Case-study pages for each project, with images and metrics
- [ ] Light and dark themes

### Later

- [ ] MDX blog with RSS
- [ ] One-command setup script that asks for name, links and colours
- [ ] Internationalisation

## Where this can go

| Direction        | Idea |
| ---------------- | ---- |
| **Product**      | A polished, themeable template that students and developers can adopt, with optional hosted customisation. |
| **Community**    | A gallery of sites built from the template. |
| **Writing**      | A technical article on keeping a WebGL scene fast: chunk splitting, lazy loading and fallbacks. |

## How to help

Pick an item from the Now column, or open a feature request. See [CONTRIBUTING.md](CONTRIBUTING.md).
